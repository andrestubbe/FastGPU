TITLE:
FastGPU: Hardware-Accelerated Compute Shaders & Direct Buffer Pipelines for Java

DESCRIPTION:
Introducing FastGPU — the zero-overhead GPU compute and acceleration substrate for the FastJava ecosystem.

FastGPU provides direct, unbloated bindings to modern GPU backends (Vulkan / OpenCL / Native Driver Buffers) allowing Java applications to dispatch mass parallel compute kernels, particle simulations, matrix ops, and tensor transforms with microsecond dispatch overhead.

🔥 TECHNICAL HIGHLIGHTS:
- ⚡ Zero-Copy Direct Buffers: Unified float and byte buffers for instant CPU-GPU memory exchanges.
- 🚀 Compute Kernel Pipeline: Compile and dispatch custom GPU compute shaders (`FastGPUKernel`) directly from Java.
- 🎯 Native Multi-Backend Dispatch: Seamlessly routes between Vulkan and OpenCL compute pipelines.
- 📉 Minimalist API: No gigantic graphics frameworks or cumbersome binding boilerplate—just pure compute acceleration.
- 🖇️ FastJava Integration: Designed to power high-density animations (FastAnimation), deep learning tensors (FastDL), and SIMD transformations.

Bringing direct GPU compute acceleration to pure Java with zero framework bloat 🚀

We are introducing **FastGPU** — the native GPU compute engine designed for the FastJava ecosystem.

Standard Java GPU bindings often carry massive game-engine dependencies, bloated wrapper classes, and heavy memory overhead. 

**FastGPU changes that:**
🔹 **Zero-Copy Memory Transfers**: Direct flat-buffer handles (`FastGPUBuffer`) between the JVM and GPU VRAM.
🔹 **Compute Kernel Dispatch**: Direct compilation and execution of parallel compute shaders (`FastGPU.dispatch()`).
🔹 **Cross-Backend Ready**: Unified Vulkan & OpenCL support for Intel, AMD, and NVIDIA hardware.
🔹 **Ecosystem Powerhouse**: Built to accelerate 100,000+ particle timelines in FastAnimation and tensor backpropagation in FastDL.

Making hardware acceleration accessible, lightweight, and blazing fast on the JVM.
